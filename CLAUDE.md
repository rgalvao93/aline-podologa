# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Sobre este repositório

Este **não é um projeto de software**. É um repositório de planejamento e conteúdo para o lançamento do negócio "Aline Podologa" — uma profissional migrando de manicure/pedicure para atuação como podóloga, criando posicionamento do zero.

Não há código-fonte, dependências, build, lint ou testes. Não crie ou sugira scaffolding de código (package.json, testes, CI, etc.) a menos que explicitamente solicitado.

## Estrutura

- `anotações-iniciais.md` — documento central de contexto do projeto: dores do negócio atual, solicitações, prazos, etapas e objetivo final. Ler este arquivo primeiro para entender qualquer pedido relacionado ao negócio. Registro original — não editar.
- `plano-lancamento.md` — cronograma de marcos até a inauguração (outubro/2026), amarrado às fases do método.
- `metodo/` — método de trabalho replicável: convenções do repositório (`README.md`), template padrão de processos (`template-processo.md`) e framework de fases (`fases-do-projeto.md`).
- `processos/` — processos do negócio, um por arquivo, todos seguindo `metodo/template-processo.md`. Novos processos devem usar esse template; lacunas de informação do negócio ficam marcadas como `[PENDENTE: ...]` — nunca inventar conteúdo do negócio.
- `docs/` — imagens de referência (fotos) para uso em materiais de divulgação/catálogo.

## Contexto de negócio (de `anotações-iniciais.md`)

- **Prazo-chave**: inauguração da Aline Podologa em outubro (do ano corrente); objetivo final é ter clientes já captados até a inauguração.
- **Dor principal**: perda de tempo respondendo dúvidas repetidas de clientes no negócio atual — motiva o interesse em automação de atendimento/agendamento.
- **Frentes solicitadas**: novos atendimentos, automação, agendamento automático, links de CTA, fotografia e filmagem, catálogo.
- **Etapas planejadas**: criar a base para receber clientes → gerar conteúdos → analisar dados → repricar (replicar) o que deu certo.
- Ainda não há material de referência (fotos/vídeos) consolidado — pendência em aberto.

## Como ajudar neste repositório

Tarefas típicas aqui são de planejamento, redação de conteúdo, organização de materiais e estruturação de automações de atendimento/agendamento — não desenvolvimento de software. Ao propor automação (ex.: agendamento automático), trate como recomendação de ferramentas/fluxos, não como implementação de código, a menos que o usuário peça explicitamente para construir algo.
